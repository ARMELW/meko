# Authentication specification

- Registration on the platform (creation of a parent account) from the landing page.
- Login with username and password.
- Password reset in case of forgetting.

## Children's Features:
- Authentication and Initial Screen:
   - Login:
The user logs in with their username and password (the parent's credentials).
   - Profile Selection:
After logging in, the user selects their profile from the available child accounts.
   - First Login:
If it is the user's first time logging in:
      - A welcome screen is displayed.
      - The user must choose an avatar to personalize their profile.
